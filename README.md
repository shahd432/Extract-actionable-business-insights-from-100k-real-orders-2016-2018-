This project focuses on performing Explatory Data Analysis (EDA) on the Brazilian e-commerce dataset provided by Olist, which contains over 100,000 real customer orders between 2016 and 2018.

The main objective of this analysis is to transform raw transactional data into meaningful business insights that can support decision-making in areas such as sales performance, customer behavior, and logistics efficiency.

Throughout the project, multiple datasets were cleaned, merged, and analyzed to answer key business questions, including revenue trends over time, top-performing product categories, customer distribution across regions, and customer satisfaction levels.

The analysis also explores operational performance by comparing actual vs. estimated delivery times, as well as identifying the most commonly used payment methods and order value patterns.

Using Python and data visualization techniques, the project delivers clear insights through charts and summaries, helping to better understand how the e-commerce platform operates and where improvements can be made.

🛠️ Tools & Technologies
Python
Pandas & NumPy
Matplotlib & Seaborn
 Key Questions We'll Answer:
1. What is the monthly revenue trend?
2. Which product categories generate the most revenue?
3. How are orders distributed by status?
4. Which Brazilian states have the most customers?
5. How satisfied are customers? (Review score analysis)
6. How does actual delivery time compare to estimated?
7. What are the most common payment methods?
8. What is the average order value distribution?
